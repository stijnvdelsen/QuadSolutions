# Quad Solutions assignment
This is my repository for the Quad Solutions code assignment.

## Requirements
The customer wants a web application for Trivia questions. There is an API that can generate the questions, but it lacks an UI. My assignement is to build this interface.

- The Open Trivia Database API is used to generate the questions `https://opentdb.com/api_config.php`.
- The user has to be able to see and answer questions.
- The user has to be able to check the answer, see the score, and see the right answers.
- The user is not allowed to see or find out the answers to the questions before answering.
